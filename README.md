## 🚀 Projects & Engineering Impact

| Project | What I built |
|---|---|
| **Hybrid RAG Document Q&A System**<br>*Independent Project*<br>`Python • LlamaIndex • Qdrant • ChromaDB` | Q&A over uploaded **PDF, DOCX, XLSX, and PPTX** files that returns **source-cited answers**.<ul><li>**Hybrid retrieval** (dense semantic + sparse BM25) on **Qdrant**, with **ChromaDB** as an additional vector database</li><li>**Parent-child chunking** and **BAAI/bge-reranker-large** re-ranking for precise, well-grounded context</li><li>**Google Gemini 3.1** generates answers with document and page citations</li></ul> |
